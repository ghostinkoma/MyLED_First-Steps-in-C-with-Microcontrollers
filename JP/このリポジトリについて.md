# C言語から C++ へのステップアップ

「C言語（Arduino）のコードは書けるけれど、C++ で自分でクラスを書くとなると何から手をつければいいのか分からず頭が真っ白になる」——そんな方々のために作成したリポジトリです。

「あ、この使い方は Arduino で触ったことがある！」と親しみを感じてもらいながら、実際にコードを動かして目で確認し、腑に落としてもらうことを目的としています。そのため、何よりも**「理解しやすさ（直感性）」**を第一優先にして設計しています。

---

## 設計書とコード

プログラムを作成する際は、まず「どんなクラスにしたいか」という設計（メンバの整理）からスタートします。

今回は「LEDの制御を通して、プログラミングの記述と視覚的な変化が直感的にリンクする」ことを意識し、必要十分な機能を揃えました。

### メンバ関数一覧

| 関数 | 役割 |
|---|---|
| `void begin(uint8_t pin)` | ピンの登録と初期化設定 |
| `void toggle(int t)` | ノンブロッキングでの点滅制御（tミリ秒間隔） |
| `void pwm(uint8_t duty)` | PWMによる明るさ制御（0〜255） |
| `void setHighInline()` | ポート直接操作による高速点灯（ON） |
| `void setLowInline()` | ポート直接操作による高速消灯（OFF） |
| `void _tick1ms()` | `delay()` に頼らないタイマー割り込み用内部処理 |

---

## C言語の経験を活かす

Arduino のサンプルコードでありがちな `delay()` を使ったブロッキング処理から一歩進み、実際の開発現場で最もよく使われる **Timer（タイマー）ペリフェラル** の仕組みが自然と学べる設計になっています。
