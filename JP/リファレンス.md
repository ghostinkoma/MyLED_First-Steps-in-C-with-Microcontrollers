# MyLED リファレンス

各クラス・各関数の詳しい仕様です。使い方がわからなくなったらここを見てください。

- 対象ヘッダ: [`src/MyLED.h`](src/MyLED.h)
- 実装: [`src/MyLED.cpp`](src/MyLED.cpp)

---

## 全体の流れ

```
① 各 LED でピンを登録         leds[i].begin(pin)
② まとめて管理・タイマー開始   LED.begin(leds, 個数)
③ 光り方を指定               LED[i].toggle(t) / LED[i].pwm(duty) など
────────────────────────────
以後、1ms ごとのタイマー割り込みが自動で点滅を処理する
```

`LED` はライブラリが用意した**唯一の管理役インスタンス**です（自分で作る必要はありません）。

## class LEDClass — LED 1 個ぶん

### `LEDClass()`（コンストラクタ）
- **説明**: LED オブジェクトを作ったときに自動で呼ばれ、状態を初期化します。
- **備考**: 内部でピン番号を `255`（=未設定の目印）にします。使う前に必ず `begin()` を呼んでください。

### `void begin(uint8_t pin)`
- **説明**: この LED が使うピンを登録し、`OUTPUT`（出力）に設定します。最初に 1 回だけ呼びます。
- **引数**: `pin` … LED をつないだピン番号。
- **動作**: AVR ではポート直接操作用の情報も取得します。最後に**消灯**した状態から始まります。
- **例**:
  ```cpp
  leds[0].begin(2);
  ```

### `void toggle(int t)`
- **説明**: `t` ミリ秒ごとに点灯↔消灯を繰り返します（点滅）。
- **引数**: `t` … 反転する間隔[ms]。**`t <= 0` を渡すと点滅を停止**します。
- **注意**: `t` は「反転間隔」です。`toggle(500)` は点滅周期 1 秒（500ms 点灯 + 500ms 消灯）。
- **内部動作**: 割り込みと変数を取り合わないよう、一瞬だけ割り込みを止めて設定を更新します。
- **例**:
  ```cpp
  LED[0].toggle(500);  // ゆっくり点滅
  LED[0].toggle(0);    // 点滅を止める（その時の状態で停止）
  ```

### `void pwm(uint8_t duty)`
- **説明**: PWM で明るさを調整します（`analogWrite` を使用）。
- **引数**: `duty` … `0`（消灯）〜`255`（全灯）の 256 段階。
- **副作用**: 呼ぶと、その LED の点滅（`toggle`）は停止します。
- **⚠️ ピン制限（AVR のみ）**: 本ライブラリは `Timer1` を点滅に使うため、
  `Timer1` ピン（**9・10 番**）の `pwm()` は動作しません。AVR では **3・5・6・11 番**を使ってください。
  ESP32 系は任意の出力ピンで OK。
- **例**:
  ```cpp
  LED[2].pwm(128);  // 約 50% の明るさ
  ```

### `void setHighInline()`
- **説明**: LED をすぐに**点灯**します。
- **実装**: AVR ではインラインアセンブラで高速にポートを操作、それ以外は `digitalWrite(pin, HIGH)`。

### `void setLowInline()`
- **説明**: LED をすぐに**消灯**します。
- **実装**: 上記の消灯版。

### `void _tick1ms()`  ※内部用
- **説明**: 1ms ごとにタイマー割り込みから呼ばれ、点滅のタイミングを数えます。
- **注意**: ユーザーが直接呼ぶ関数ではありません（頭の `_` は「内部用」の目印）。

## class LEDManager — 複数 LED の管理役

実体はライブラリが `LED` という名前で 1 個だけ用意しています。

### `void begin(LEDClass* ledArray, size_t count)`
- **説明**: 管理する LED 配列とその個数を登録し、**1ms タイマー割り込みを開始**します。
- **引数**:
  - `ledArray` … `LEDClass` 配列の先頭（配列名をそのまま渡せます）。
  - `count` … LED の個数。
- **例**:
  ```cpp
  LEDClass leds[3];
  LED.begin(leds, 3);
  ```

### `LEDClass& operator[](size_t index)`
- **説明**: `LED[0]` のように**添字で LED にアクセス**できるようにする演算子です。
- **引数**: `index` … 0 から始まる LED の番号。
- **安全対策**: 範囲外の番号や `begin()` 前のアクセスでも、落ちないよう保護しています
  （範囲外は 0 番を返します）。
- **例**:
  ```cpp
  LED[1].toggle(200);
  ```

### `void initTimer1()`  ※内部用
- **説明**: 1ms 周期のタイマー割り込みをセットアップします（`begin()` から自動で呼ばれます）。
- **実装の中身**:
  - AVR: `Timer1` を CTC モード・プリスケーラ 64 で 1kHz に設定。
  - ESP32: 汎用ハードウェアタイマーを 1MHz 分解能で作り、1000μs ごとに割り込み。
    （arduino-esp32 2.x / 3.x の両 API に対応）

### `void _tickAll()`  ※内部用
- **説明**: 割り込みから呼ばれ、登録された全 LED の `_tick1ms()` をまとめて実行します。

## グローバル変数

### `extern LEDManager LED;`
- プログラム全体で共有される管理役インスタンス。実体は `MyLED.cpp` にあります。
- ユーザーはこの `LED` を通して各 LED を操作します（`LED.begin(...)`, `LED[i]...`）。

## よくある質問

**Q. `LED` と `leds` は何が違う?**
A. `leds` は自分で作る「LED の配列（部品）」、`LED` はライブラリが持つ「管理役（司令塔）」です。
   `LED.begin(leds, 3)` で司令塔に部品を預けるイメージです。

**Q. `loop()` に何も書かなくていいの?**
A. はい。点滅はタイマー割り込みが自動で行うので、`loop()` は他の処理に使えます。

**Q. 明るさを変えながら点滅させたい**
A. 現状の `pwm()` と `toggle()` は排他（片方が動くともう片方は止まる）です。
   まずは基本を理解する教材として、シンプルさを優先した設計になっています。

**Q. `_` で始まる関数は?**
A. ライブラリ内部が使う関数の目印です。ユーザーは呼ばないでください。
