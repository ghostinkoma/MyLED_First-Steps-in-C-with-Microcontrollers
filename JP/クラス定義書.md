# MyLED クラス定義書

このドキュメントは、MyLED ライブラリの**クラス設計（内部構造）**をまとめた設計書です。
「なぜこう作ったのか」「どのクラスが何を担当するのか」を理解するために読んでください。

---

## 1. 設計方針

| 方針 | 内容 |
|---|---|
| 責務の分離 | 「LED 1 個」と「LED 全体の管理」を別クラスにする |
| ノンブロッキング | 点滅は `delay()` ではなくタイマー割り込みで行い、`loop()` を止めない |
| 直感的な記法 | `LED[0].toggle(500)` のように配列風に書けるようにする |
| 移植性 | マイコン依存部分を `#if defined(...)` に閉じ込め、使う側は共通化する |

---

## 2. クラス構成図

```
                 ┌─────────────────────────────┐
                 │        LEDManager  (LED)     │  司令塔（1個だけ）
                 │  - _leds : LEDClass*         │
                 │  - _count : size_t           │
                 │  + begin(array, count)       │
                 │  + operator[](i) ───────────┐│
                 │  + initTimer1() / _tickAll() ││
                 └──────────────────────────────┘│
                        │ 管理（配列を保持）        │ LED[i] でアクセス
                        ▼                         ▼
     ┌───────────┐  ┌───────────┐  ┌───────────┐
     │ LEDClass  │  │ LEDClass  │  │ LEDClass  │   部品（好きな個数）
     │  leds[0]  │  │  leds[1]  │  │  leds[2]  │
     └───────────┘  └───────────┘  └───────────┘

  ［1ms タイマー割り込み］→ LED._tickAll() → 各 leds[i]._tick1ms()
```

---

## 3. クラス定義: `LEDClass`（LED 1 個ぶん）

**役割**: 1 個の LED の状態を保持し、点灯・消灯・点滅・調光を行う。

### メンバ変数

| 変数 | 型 | 公開 | 説明 |
|---|---|---|---|
| `_pin` | `uint8_t` | private | 使用ピン番号（255=未初期化） |
| `_port` | `volatile uint8_t*` | private | 出力ポートレジスタのアドレス（AVR のみ使用） |
| `_bitmask` | `uint8_t` | private | ポート内のビット位置（AVR のみ使用） |
| `_toggle_interval_ms` | `volatile uint16_t` | private | 点滅の反転間隔[ms]（0=点滅しない） |
| `_timer_counter` | `volatile uint16_t` | private | 経過 ms を数えるカウンタ |
| `_toggle_enabled` | `volatile bool` | private | 点滅中フラグ |
| `_state` | `volatile bool` | private | 現在 HIGH か LOW か |

> `volatile` は「割り込みの中で書き換わる変数」に付ける印。
> コンパイラの最適化による読み飛ばしを防ぐために必要です。

### メソッド

| メソッド | 公開 | 責務 |
|---|---|---|
| `LEDClass()` | public | 状態を安全な初期値に初期化 |
| `begin(uint8_t pin)` | public | ピン登録・出力設定・（AVR）ポート情報取得 |
| `setHighInline()` | public | 点灯（AVR=アセンブラ / 他=digitalWrite） |
| `setLowInline()` | public | 消灯（同上） |
| `toggle(int t)` | public | t ms ごとの点滅を設定（0 で停止） |
| `pwm(uint8_t duty)` | public | PWM 調光（0〜255） |
| `_tick1ms()` | public(内部用) | 割り込みから 1ms ごとに呼ばれ点滅を進める |

---

## 4. クラス定義: `LEDManager`（複数 LED の管理役）

**役割**: 複数の `LEDClass` を束ね、タイマー割り込みを 1 本立てて全 LED を駆動する。
実体はグローバル変数 `LED` として 1 個だけ存在する（シングルトン的な使い方）。

### メンバ変数

| 変数 | 型 | 公開 | 説明 |
|---|---|---|---|
| `_leds` | `LEDClass*` | private | 管理する LED 配列の先頭アドレス |
| `_count` | `size_t` | private | LED の個数 |

### メソッド

| メソッド | 公開 | 責務 |
|---|---|---|
| `LEDManager()` | public | ポインタ/個数を初期化 |
| `begin(LEDClass*, size_t)` | public | 配列を登録し `initTimer1()` を起動 |
| `operator[](size_t)` | public | `LED[i]` アクセス（範囲外は保護） |
| `initTimer1()` | public(内部用) | 1ms タイマー割り込みのセットアップ |
| `_tickAll()` | public(内部用) | 全 LED の `_tick1ms()` を呼ぶ |

---

## 5. 動作シーケンス

### 初期化時
```
setup()
 ├─ leds[i].begin(pin)        … 各LED: ピン設定・消灯
 └─ LED.begin(leds, count)
       └─ initTimer1()        … 1ms タイマー割り込みを開始
```

### 実行時（1ms ごと、自動）
```
[タイマー割り込み発生]
 └─ LED._tickAll()
      └─ 各 leds[i]._tick1ms()
            └─ カウンタが間隔に達したら _state 反転 → setHigh/LowInline()
```

## 6. プラットフォーム依存の切り替え

タイマーと点灯方法だけがマイコンごとに違います。他は共通です。

| 部分 | AVR (`__AVR__`) | ESP32 (`ESP32`) | その他 |
|---|---|---|---|
| タイマー | `Timer1` CTC / `ISR(TIMER1_COMPA_vect)` | `hw_timer_t` + `IRAM_ATTR` 割り込み | なし（点滅無効） |
| 点灯/消灯 | インラインアセンブラ（ポート直接） | `digitalWrite` | `digitalWrite` |
| ESP32 API | — | 3.x=`timerBegin(1MHz)+timerAlarm` / 2.x=`timerAlarmWrite` | — |

> 判定は実装ファイル `MyLED.cpp` の `#if defined(__AVR__) / #elif defined(ESP32) / #else`
> で行っています。使う側のスケッチ（.ino）は変更不要です。

## 7. 既知の制約（教材としての割り切り）

| 制約 | 理由・回避策 |
|---|---|
| AVR で 9・10 番の `pwm()` 不可 | 点滅用に Timer1 を占有するため。3・5・6・11 番を使う |
| `pwm()` と `toggle()` は排他 | シンプルさ優先。片方を呼ぶともう片方は止まる |
| 点滅間隔の分解能は 1ms | タイマー割り込み周期に一致 |
| ESP32 の割り込みで `digitalWrite` を使用 | 分かりやすさ優先。厳密には直接レジスタ操作の方が安全 |

## 8. 用語ミニ辞典

- **クラス / インスタンス**: 設計図（class）と、それを実体化した部品（instance）。
- **`private` / `public`**: 外から触れる（public）か、内部専用（private）か。
- **演算子オーバーロード**: `[]` などの記号の動作を自分のクラス用に定義すること。
- **タイマー割り込み**: 一定時間ごとにハードウェアが自動でプログラムを呼び出すしくみ。
- **`volatile`**: 「勝手に最適化しないで」とコンパイラに伝える印（割り込み共有変数に付ける）。
- **CTC モード**: AVR タイマーが指定値に達したら自動で 0 に戻るモード。周期割り込みに使う。
