# MyLED 类定义说明书

本文档是 MyLED 库的**类设计（内部结构）**说明书。
旨在帮助理解“为何这样设计”以及“各个类分别负责什么功能”。

---

## 1. 设计方针

| 方针 | 内容 |
|---|---|
| 职责分离 | 将“单个 LED”与“LED 整体管理”拆分为不同的类 |
| 非阻塞 | 闪烁采用定时器中断而非 `delay()`，不阻塞 `loop()` 主循环 |
| 直观的语法 | 支持像数组一样的直观写法，如 `LED[0].toggle(500)` |
| 可移植性 | 将依赖具体微控制器（MCU）的代码封装在 `#if defined(...)` 中，对使用者保持统一接口 |

## 3. 类定义: `LEDClass`（代表单个 LED）

**职责**: 保存单个 LED 的状态，控制其点亮、熄灭、闪烁以及调光。

### 成员变量

| 变量 | 类型 | 访问权限 | 说明 |
|---|---|---|---|
| `_pin` | `uint8_t` | private | 引脚编号（255 = 未初始化） |
| `_port` | `volatile uint8_t*` | private | 输出端口寄存器地址（仅限 AVR） |
| `_bitmask` | `uint8_t` | private | 端口内的位掩码（仅限 AVR） |
| `_toggle_interval_ms` | `volatile uint16_t` | private | 闪烁翻转间隔 [ms]（0 = 不闪烁） |
| `_timer_counter` | `volatile uint16_t` | private | 用于计算已过毫秒数的计数器 |
| `_toggle_enabled` | `volatile bool` | private | 闪烁启用标志 |
| `_state` | `volatile bool` | private | 当前输出状态（HIGH 或 LOW） |

> `volatile` 用于修饰“会在中断服务程序中被修改的变量”。
> 可以防止编译器因过度优化而忽略对该变量值的更新读取。

### 成员函数（方法）

| 方法 | 访问权限 | 职责 |
|---|---|---|
| `LEDClass()` | public | 将状态初始化为安全初始值 |
| `begin(uint8_t pin)` | public | 注册引脚、配置输出模式及（AVR）获取端口寄存器信息 |
| `setHighInline()` | public | 立即点亮（AVR 使用汇编指令 / 其他平台使用 `digitalWrite`） |
| `setLowInline()` | public | 立即熄灭（同上） |
| `toggle(int t)` | public | 设置每隔 t ms 翻转一次状态（传入 0 停止闪烁） |
| `pwm(uint8_t duty)` | public | PWM 调光（亮度范围 0〜255） |
| `_tick1ms()` | public (内部用) | 每 1ms 由中断机制调用，推进闪烁计时 |

## 4. 类定义: `LEDManager`（多个 LED 的管理者）

**职责**: 管理多个 `LEDClass` 实例，并启动一个硬件定时器中断统一驱动所有 LED。
在全局范围仅存在 1 个实体 `LED`（单例设计模式用法）。

### 成员变量

| 变量 | 类型 | 访问权限 | 说明 |
|---|---|---|---|
| `_leds` | `LEDClass*` | private | 被管理的 LED 数组首地址指针 |
| `_count` | `size_t` | private | LED 的数量 |

### 成员函数（方法）

| 方法 | 访问权限 | 职责 |
|---|---|---|
| `LEDManager()` | public | 初始化指针与数量计数 |
| `begin(LEDClass*, size_t)` | public | 注册 LED 数组并启动 `initTimer1()` 定时器 |
| `operator[](size_t)` | public | 重载 `[]` 运算符，提供 `LED[i]` 访问接口（带越界保护） |
| `initTimer1()` | public (内部用) | 配置 1ms 周期定时器中断 |
| `_tickAll()` | public (内部用) | 遍历并调用所有 LED 实例的 `_tick1ms()` |

---

## 5. 执行时序（Sequence）

### 初始化阶段
```
setup()
 ├─ leds[i].begin(pin)        … 每个 LED：配置引脚并初始熄灭
 └─ LED.begin(leds, count)
        └─ initTimer1()       … 启动 1ms 定时器中断
```

### 运行阶段（每 1ms 自动触发）
```
[定时器中断触发]
 └─ LED._tickAll()
      └─ 调用各个 leds[i]._tick1ms()
            └─ 计数器达到设定的间隔时翻转 _state → 调用 setHigh/LowInline()
```

## 6. 平台依赖的差异化实现

仅定时器中断与引脚控制方式因微控制器（MCU）而异，其余代码全平台通用。

| 模块 | AVR (`__AVR__`) | ESP32 (`ESP32`) | 其他平台 |
|---|---|---|---|
| 定时器 | `Timer1` CTC 模式 / `ISR(TIMER1_COMPA_vect)` | `hw_timer_t` + `IRAM_ATTR` 中断函数 | 无（闪烁功能无效） |
| 点亮/熄灭 | 内联汇编（直接寄存器操作） | `digitalWrite` | `digitalWrite` |
| ESP32 API | — | 3.x: `timerBegin(1MHz)+timerAlarm` / 2.x: `timerAlarmWrite` | — |

> 平台判定在实现文件 `MyLED.cpp` 中通过 `#if defined(__AVR__) / #elif defined(ESP32) / #else` 条件编译完成。使用者在 `.ino` 主程序中无需关注这些差异。

## 7. 已知限制（教学示例的权衡设计）

| 限制 | 原因及替代方案 |
|---|---|
| AVR 架构下 9、10 号引脚无法使用 `pwm()` | 因为 Timer1 已被占用用于产生闪烁中断。请改用 3、5、6、11 号引脚 |
| `pwm()` 与 `toggle()` 互斥 | 优先考虑代码易懂性。调用其中一个会自动停止另一个 |
| 闪烁时间分辨率为 1ms | 受限于定时器中断的 1ms 触发周期 |
| ESP32 中断函数中使用 `digitalWrite` | 优先保证易读性。严格意义上直接操作寄存器更安全 |

## 8. 迷你名词词典

- **类 (Class) / 实例 (Instance)**: 设计图纸（Class）与依据图纸生成的实体部件（Instance）。
- **`private` / `public`**: 外部可直接访问（public）或仅供内部使用（private）。
- **运算符重载 (Operator Overloading)**: 自定义如 `[]` 等符号在当前类对象上的行为。
- **定时器中断 (Timer Interrupt)**: 硬件按固定时间间隔自动暂停主程序并调用特定代码的机制。
- **`volatile`**: 告知编译器“请勿对此变量进行优化/缓存”的修饰符（用于中断共享变量）。
- **CTC 模式**: AVR 定时器达到设定计数值后自动清零并触发中断的模式，常用于周期性定时。
