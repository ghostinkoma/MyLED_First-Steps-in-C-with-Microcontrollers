# MyLED 参考手册

本文档提供了各个类和函数的详细说明。如果不确定如何使用，请查阅此文档。

- 目标头文件：[`src/MyLED.h`](src/MyLED.h)
- 具体实现：[`src/MyLED.cpp`](src/MyLED.cpp)

## 整体流程

```
① 为各个 LED 注册引脚           leds[i].begin(pin)
② 集中管理并启动定时器         LED.begin(leds, 数量)
③ 指定发光模式                 LED[i].toggle(t) / LED[i].pwm(duty) 等
────────────────────────────
此后，每 1ms 一次的定时器中断会自动处理闪烁逻辑
```

`LED` 是库预先创建好的**唯一管理者实例**（无需自己手动创建）。

## class LEDClass — 单个 LED 的控制

### `LEDClass()`（构造函数）
- **说明**：创建 LED 对象时自动调用，用于初始化状态。
- **备注**：内部将引脚编号设置为 `255`（表示未设置的标记）。在使用前务必调用 `begin()`。

### `void begin(uint8_t pin)`
- **说明**：注册该 LED 使用的引脚，并将其设置为 `OUTPUT`（输出模式）。只需在初始化时调用 1 次。
- **参数**：`pin` … 连接 LED 的引脚编号。
- **行为**：在 AVR 架构上，还会获取用于直接操作端口的相关信息。初始状态为**熄灭**。
- **示例**：
  ```cpp
  leds[0].begin(2);
  ```

### `void toggle(int t)`
- **说明**：每隔 `t` 毫秒重复“点亮 ↔ 熄灭”的状态翻转（闪烁）。
- **参数**：`t` … 翻转的时间间隔 [ms]。**传入 `t <= 0` 可停止闪烁**。
- **注意**：`t` 指的是“翻转间隔”。例如 `toggle(500)` 的闪烁周期为 1 秒（500ms 点亮 + 500ms 熄灭）。
- **内部行为**：为了避免与中断冲突，内部会短暂暂停中断以安全地更新配置。
- **示例**：
  ```cpp
  LED[0].toggle(500);  // 慢速闪烁
  LED[0].toggle(0);    // 停止闪烁（保持当前状态）
  ```

### `void pwm(uint8_t duty)`
- **说明**：通过 PWM 调节亮度（内部使用 `analogWrite`）。
- **参数**：`duty` … 亮度级别，从 `0`（熄灭）到 `255`（全亮）共 256 阶。
- **副作用**：调用此函数后，该 LED 的闪烁模式（`toggle`）将自动停止。
- **⚠️ 引脚限制（仅限 AVR）**：本库占用 `Timer1` 用于处理闪烁，因此连接到 `Timer1` 的**9 号和 10 号引脚上的 `pwm()` 无法正常工作**。在 AVR 上请使用 **3、5、6、11 号引脚**。ESP32 系列可以使用任意输出引脚。
- **示例**：
  ```cpp
  LED[2].pwm(128);  // 约 50% 亮度
  ```

### `void setHighInline()`
- **说明**：立即**点亮** LED。
- **实现**：在 AVR 上使用内联汇编进行高速端口操作，其他平台使用 `digitalWrite(pin, HIGH)`。

### `void setLowInline()`
- **说明**：立即**熄灭** LED。
- **实现**：上述点亮函数的熄灭版本。

### `void _tick1ms()`  ※内部使用
- **说明**：每隔 1ms 由定时器中断自动调用，用于计算闪烁计时。
- **注意**：非用户直接调用的函数（开头的 `_` 代表“内部专有”）。

## class LEDManager — 多个 LED 的管理者

库内部已创建好一个名为 `LED` 的唯一实例供直接使用。

### `void begin(LEDClass* ledArray, size_t count)`
- **说明**：注册要管理的 LED 数组及其数量，并**启动 1ms 定时器中断**。
- **参数**：
  - `ledArray` … `LEDClass` 数组的首地址（直接传入数组名即可）。
  - `count` … LED 的数量。
- **示例**：
  ```cpp
  LEDClass leds[3];
  LED.begin(leds, 3);
  ```

### `LEDClass& operator[](size_t index)`
- **说明**：运算符重载，支持像 `LED[0]` 一样**通过下标访问各个 LED**。
- **参数**：`index` … 从 0 开始的 LED 编号。
- **安全防护**：即使访问超出范围或在 `begin()` 调用前访问，内部也做好了防护处理，不会导致崩溃（越界时默认返回第 0 个）。
- **示例**：
  ```cpp
  LED[1].toggle(200);
  ```

### `void initTimer1()`  ※内部使用
- **说明**：初始化 1ms 周期的定时器中断（由 `begin()` 自动调用）。
- **实现细节**：
  - AVR: 将 `Timer1` 配置为 CTC 模式、预分频 64，产生 1kHz 中断。
  - ESP32: 创建分辨率为 1MHz 的通用硬件定时器，每 1000μs 触发一次中断。（同时兼容 arduino-esp32 2.x / 3.x API）

### `void _tickAll()`  ※内部使用
- **说明**：由中断调用，集中执行已注册的所有 LED 的 `_tick1ms()`。

## 全局变量

### `extern LEDManager LED;`
- 在整个程序中共享的唯一管理者实例，实体定义在 `MyLED.cpp` 中。
- 用户通过这个 `LED` 对象来操作各个 LED（例如 `LED.begin(...)`, `LED[i]...`）。

## 常见问题 (FAQ)

**Q. `LED` 和 `leds` 有什么区别？**
A. `leds` 是由你自己创建的“LED 数组（组件）”，而 `LED` 是库自带的“管理者（司令官）”。`LED.begin(leds, 3)` 相当于把组件托付给司令官统一调配。

**Q. 真的可以在 `loop()` 里什么都不写吗？**
A. 是的。因为闪烁逻辑由定时器中断在后台自动处理，`loop()` 可以完全留给其他主逻辑使用。

**Q. 可以一边调节亮度（PWM）一边闪烁吗？**
A. 目前 `pwm()` 和 `toggle()` 是互斥的（启动其中一个会停止另一个）。为了保持代码作为教学器材的简洁易懂，设计上优先考虑了直观性。

**Q. 以 `_` 开头的函数是什么意思？**
A. 表示该函数仅供库内部使用，用户无需在自己的代码中调用。
