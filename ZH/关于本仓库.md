# 从 C 语言跨越到 C++

“虽然会写 C 语言（Arduino）代码，但如果要自己用 C++ 写一个类（Class），却完全不知道该从何下手，大脑一片空白”——本仓库就是专门为有此类困惑的人士打造的。

本仓库旨在让大家在实际运行代码、眼见为实的过程中获得亲切感，产生“啊，这种用法我在 Arduino 里接触过！”的共鸣，从而真正融会贯通。因此，我们在设计时将**“易懂性（直观性）”**放在了第一位。

---

## 设计文档与代码

在编写程序时，首先要从“想设计一个怎样的类”（整理成员）开始。

本次我们注重“通过控制 LED，使编程代码与视觉上的硬件变化产生直观联动”，并精简提炼出了必要且充分的功能。

### 成员函数列表

| 函数 | 作用 |
|---|---|
| `void begin(uint8_t pin)` | 引脚注册与初始化设置 |
| `void toggle(int t)` | 非阻塞式的闪烁控制（间隔 t 毫秒） |
| `void pwm(uint8_t duty)` | 通过 PWM 进行亮度控制（0〜255） |
| `void setHighInline()` | 通过直接操作端口实现高速点亮（ON） |
| `void setLowInline()` | 通过直接操作端口实现高速熄灭（OFF） |
| `void _tick1ms()` | 用于定时器中断的内部处理（不依赖 `delay()`） |
