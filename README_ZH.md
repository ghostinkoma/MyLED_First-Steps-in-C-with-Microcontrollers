# MyLED

这是一个适用于 Arduino / ESP32 的教学用库，旨在通过 **定时器中断** 集中控制多个 LED。
无需阻塞 `loop()` 函数，即可让多个 LED 以“不同的模式同时”闪烁或调光。

为了方便学习编程（C++ / 类 / 单片机）的新手，源码中每一行都附有详细的日文注释。

---

## 特性

- **直观的语法，如 `LED[0].toggle(500)`** — 通过运算符重载实现类似于数组的访问方式
- **非阻塞** — 由 1ms 定时器中断负责处理闪烁，`loop()` 函数可自由用于其他任务
- **多平台支持** — 同一份代码（Sketch）可以直接运行在 AVR 和 ESP32 上
- **适合教学** — 可学习类设计、中断机制以及（作为进阶内容的）AVR 内联汇编

## 支持的单片机

| 单片机 | 闪烁定时器 | 点亮/熄灭方式 |
|---|---|---|
| Arduino UNO / Nano（ATmega328P, 16MHz）| Timer1（CTC, 1kHz）| 内联汇编（高速端口操作）|
| LGT8F328P | Timer1 | 内联汇编 |
| ESP32 / ESP32-C3 / ESP32-S2 / ESP32-S3 | 硬件定时器 | `digitalWrite` |
| 其他 | （无/禁用闪烁）| `digitalWrite` |

> 单片机之间的差异已在源码内部通过 `#if defined(...)` 自动切换。
> **使用者编写的代码在任何单片机上都是完全相同的**。

## 使用方法（最简示例）

```cpp
#include "src/MyLED.h"

LEDClass leds[3];          // 准备 3 个 LED 实例

void setup() {
    leds[0].begin(2);      // 注册使用的引脚
    leds[1].begin(4);
    leds[2].begin(11);

    LED.begin(leds, 3);    // 将数组和数量交给管理者（在此处启动定时器）

    LED[0].toggle(500);    // 每 500ms 翻转一次（闪烁）
    LED[1].toggle(200);    // 每 200ms 翻转一次（闪烁）
    LED[2].pwm(128);       // 亮度设为 50%
}

void loop() {
    // 无需在此编写任何代码（闪烁由中断自动处理）
}
```

## API 快速参考

| 编写方式 | 含义 |
|---|---|
| `leds[i].begin(pin)` | 注册第 i 个 LED 使用的引脚并设置为输出模式 |
| `LED.begin(leds, 3)` | 集中管理 3 个 LED 并启动定时器 |
| `LED[i].toggle(t)` | 每隔 t 毫秒闪烁一次（`t = 0` 时停止）|
| `LED[i].pwm(duty)` | 指定亮度（0〜255，PWM 调光）|
| `LED[i].setHighInline()` | 立即点亮 |
| `LED[i].setLowInline()`  | 立即熄灭 |

详细信息请参阅 [Reference.md](Reference.md)。

## 注意事项

- **PWM 引脚选择（仅限 AVR）**: 本库占用 `Timer1` 用于处理闪烁。因此，连接到 `Timer1` 的 **9 号和 10 号引脚上的 `pwm()` 无法正常工作**。如果要在 AVR 上使用 `pwm()`，请选择 **3、5、6、11 号引脚**。ESP32 系列则可以使用任意输出引脚。
- **`toggle()` 中的 `t` 是“状态翻转的时间间隔”**。例如 `toggle(500)` 表示亮 500ms → 灭 500ms（完整的闪烁周期为 1 秒）。
- 由于是在定时器中断内部操作 LED，`toggle()` 在内部会短暂暂停中断，以安全地更新配置。
