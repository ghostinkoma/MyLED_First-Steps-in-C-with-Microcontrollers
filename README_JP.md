# MyLED

複数の LED を **タイマー割り込み** でまとめて制御する、Arduino / ESP32 向けの学習用ライブラリです。
`loop()` を一切止めずに、LED を「別々のパターンで同時に」点滅・調光できます。

プログラミング（C++ / クラス / マイコン）を学ぶ人向けに、
ソースコードには一行ずつ日本語コメントを付けてあります。

---

## 特徴

- **`LED[0].toggle(500)` のように直感的に書ける** — 演算子オーバーロードで配列風にアクセス
- **ノンブロッキング** — 点滅は 1ms タイマー割り込みが担当し、`loop()` は自由に使える
- **マルチプラットフォーム** — 1つのスケッチが AVR でも ESP32 でもそのまま動く
- **教材向け** — クラス設計・割り込み・（発展として）AVR インラインアセンブラを学べる

## 対応マイコン

| マイコン | 点滅タイマー | 点灯/消灯の方法 |
|---|---|---|
| Arduino UNO / Nano（ATmega328P, 16MHz）| Timer1（CTC, 1kHz）| インラインアセンブラ（高速ポート操作）|
| LGT8F328P | Timer1 | インラインアセンブラ |
| ESP32 / ESP32-C3 / ESP32-S2 / ESP32-S3 | ハードウェアタイマー | `digitalWrite` |
| その他 | （なし・点滅無効）| `digitalWrite` |

> マイコンごとの違いは `#if defined(...)` でソース内部で自動的に切り替わります。
> **使う側のスケッチはどのマイコンでも同じ**です。

## 配線

```
  マイコンのピン ──[抵抗 220〜330Ω]──▷|── GND
                                     LED
```

LED の足の長い方（アノード, +）を抵抗側に、短い方（カソード, −）を GND につなぎます。

## 使い方（最短の例）

```cpp
#include "src/MyLED.h"

LEDClass leds[3];          // LED を3個ぶん用意

void setup() {
    leds[0].begin(2);      // 使うピンを登録
    leds[1].begin(4);
    leds[2].begin(11);

    LED.begin(leds, 3);    // 管理役に配列と個数を渡す（ここでタイマー起動）

    LED[0].toggle(500);    // 500ms ごとに点滅
    LED[1].toggle(200);    // 200ms ごとに点滅
    LED[2].pwm(128);       // 明るさ 50%
}

void loop() {
    // 何も書かなくてOK（点滅は割り込みが自動で行う）
}
```

## API 早見表

| 書き方 | 意味 |
|---|---|
| `leds[i].begin(pin)` | i 番目の LED が使うピンを登録・出力設定 |
| `LED.begin(leds, 3)` | 3個の LED をまとめて管理し、タイマーを開始 |
| `LED[i].toggle(t)` | t ミリ秒ごとに点滅（`t = 0` で停止）|
| `LED[i].pwm(duty)` | 明るさを 0〜255 で指定（PWM）|
| `LED[i].setHighInline()` | すぐに点灯 |
| `LED[i].setLowInline()`  | すぐに消灯 |

詳細は [リファレンス.md](リファレンス.md) を参照してください。

## 注意点

- **PWM のピン選び（AVR のみ）**: 本ライブラリは点滅用に `Timer1` を占有します。
  `Timer1` につながる **9・10 番ピンの `pwm()` は正しく動きません**。
  AVR で `pwm()` を使うなら **3・5・6・11 番**を選んでください。ESP32 系は任意の出力ピンでOK。
- **`toggle()` の `t` は「反転する間隔」**です。`toggle(500)` は 500ms 点灯 → 500ms 消灯（点滅周期は 1 秒）。
- 割り込みの中から LED を操作するため、`toggle()` は内部で一瞬だけ割り込みを止めて安全に設定を更新します。
